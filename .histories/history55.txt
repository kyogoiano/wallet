# 5. Security hook is good, but 000.9.3 must own TLS termination semantics

The plan says:

That's useful infrastructure plumbing, but be careful with the word **termination**.

There are actually potentially three TLS boundaries:

```text
Client
  │ TLS 1.3
  ▼
Ingress/LB
  │
  │ TLS or plaintext
  ▼
Edge
  │
  │ TLS
  ▼
NATS
  │
  │ TLS
  ▼
Core
```

000.9.2 should provide the ability to configure these.

But **000.9.3 should decide the security policy**.

I'd change the plan language to:

> TLS-capable ingress and internal transport configuration MUST be supported; TLS termination and re-encryption policy are deployment-profile concerns and are finalized by SPEC-000.9.3.

That keeps the boundaries clean.
