# Getting Started

## Dependencies
- An system with docker installed
- With no docker you can only build and see the test executions

## How to build and run tests

./gradlew clean build

## 🚀 How to Run

docker compose up

-stoppin:
docker compose down -v

## OPEN API V3.1 doc
http://localhost:8080/v3/api-docs

## SWAGGER UI: 
http://localhost:8080/swagger-ui/index.html
